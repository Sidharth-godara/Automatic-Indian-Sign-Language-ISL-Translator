# Two-Way Indian Sign Language Translator using AI

## About the Project
An AI-powered communication system designed to bridge the communication gap between deaf and hearing individuals using Indian Sign Language (ISL).

## Key Features
- Real-time ISL gesture recognition.
- Conversion of signs into English and Hindi text.
- Text-to-Speech output.
- English/Hindi text-to-ISL visual translation.
- Computer vision-based hand tracking.
- AI-powered gesture recognition.

## Technology Stack
- Python
- OpenCV
- MediaPipe
- TensorFlow
- NumPy

## System Architecture

**ISL to Text/Speech:**
Camera → Hand Tracking → Gesture Recognition → Translation → Voice Output

**Text/Speech to ISL:**
Text/Speech Input → Language Processing → ISL Mapping → Visual Sign Output
